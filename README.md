# Week 2 - Advanced JavaScript & Express API

This repository contains tasks and examples for Week 2, properly structured by days and topics.

## Structure

### Day 3: Array Methods
Located in `week-2/day-3/`
Contains various scripts demonstrating advanced array methods (`filter`, `map`, `reduce`, `find`, `findIndex`):
- **`temperatureArrayOps.js`**: Converting and filtering temperatures.
- **`coursesArrayOps.js`**: String manipulation within arrays.
- **`marksArrayOps.js`**: Grading and filtering marks.
- **`shoppingCartOps.js`**: E-commerce cart total and inventory calculations.
- **`studentPerformanceOps.js`**: Student grading logic.
- **`employeePayrollOps.js`**: Salary calculations and bonus logic.
- **`movieStreamingOps.js`**: Movie ratings and filtering.
- **`bankTransactionOps.js`**: Banking transaction logic.

### Day 4: ES6 Features & Async Logic
Located in `week-2/day-4/`
- **`classesExample1.js` & `classesExample2.js`**: Object-oriented JavaScript using ES6 Classes.
- **`shallowCopy.js`**: Demonstrating shallow vs deep copies.
- **`spreadOperator.js`**: Usage of the `...` spread operator.
- **`timerExample1.js` & `timerExample2.js`**: Asynchronous JavaScript using `setTimeout` and `setInterval`.

### Modules
- **`module-1/`**: Basic modular JavaScript, including validators.
- **`module-2/`**: A modular e-commerce architecture containing app logic, carts, and discounts.

### Express API
Located in `week-2/express-api/`
- Contains an Express.js server (`server.js`) with dedicated API routing in the `API/` folder.
- **`req.http`**: API testing file for use with the REST Client extension.
